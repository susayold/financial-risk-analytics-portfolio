# Block A public evidence mirror

This folder contains a sanitized, recruiter-readable evidence layer for the public Block A website. It contains aggregate counts, definitions, controls and reconciliation results only. Raw LendingClub files, row-level records and private Drive artifacts are intentionally excluded.

| Artifact | Purpose |
| --- | --- |
| [Block A status](block-a-status.md) | Release scope, status and claim boundary |
| [Source manifest](source-manifest.md) | Source hierarchy and allowed analytical roles |
| [Archive verification](archive-verification.md) | Retrieval and format control summary |
| [Bridge audit](bridge-audit.md) | Figshare matching and coverage reconciliation |
| [Field concordance](field-concordance.md) | Cross-source field checks |
| [Feature contract](feature-contract.md) | Champion whitelist and exclusions |
| [Preprocessing governance](preprocessing-governance.md) | Temporal fitting and leakage controls |
| [Audit run manifest](audit-run-manifest.md) | Reproducibility and QA summary |

The canonical raw/source records and detailed working evidence remain separately governed. This public mirror is a summary layer, not a raw-data distribution.
