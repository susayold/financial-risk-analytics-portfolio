KEY RISKS & CONTROLS

Limitations are part of the deliverable.

Every risk has an impact, a control, and a residual position that can be revisited in later blocks.

R01 MEDIUM

Resolved-only population

Impact

Temporal representativeness.

Control

Qualified OOT / Historical Shadow claims.

R02 MEDIUM

Enrichment coverage

Impact

Pricing/economics may not generalize to full core.

Control

Matched-subset reporting.

R03 MEDIUM

LGD / EAD not directly observed

Impact

Expected-loss analysis is assumption-sensitive.

Control

Explicit scenario / proxy labeling.

R04 LOW

Impact

Control

R05 LOW

DTI extremes

Impact

Outlier-driven instability.

Control

Control

09

RISK ECONOMICS BOUNDARY

Expected Loss is a contract, not a finished result.

Block A defines the interfaces for later risk economics without inventing a loss distribution today.

Expected Loss = Predicted PD × LGD × EAD

Projected economics will be built from model output, an explicit loss assumption, and a governed exposure proxy.

PRE-COMMITTED CONTRACT · BLOCK D IMPLEMENTATION
PD

Model-estimated probability

Block C output.

LGD

Scenario assumption

Until observed evidence exists.

EAD

Loan amount / governed exposure proxy

Until stronger evidence exists.

!

Target discipline: actual_default is used to train and validate PD. It is not substituted for predicted PD in projected Expected Loss.
