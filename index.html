How to read this project

The evidence is useful because the boundaries are explicit.

Target

Final-resolution BAD / GOOD analytical outcome.

Not a verified 12-month regulatory PD.
Loss

LGD, EAD and expected-loss values are analytical proxies.

Not IFRS 9 / Basel production estimates.
Policy

Approval, review and decline outputs are historical simulations.

Not a deployed underwriting policy.
Deployment

The website exposes sanitized aggregate evidence only.

No production authorization is claimed.
